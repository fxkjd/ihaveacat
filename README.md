Source code for https://ihavea.cat/.

A responsive ASCII-art night scene featuring the current lunar phase. Explore the stars and constellations from different coordinates and directions.

Star data comes from the [HYG Database v4.1](https://github.com/astronexus/HYG-Database); constellation figures come from [Dominic Ford’s constellation stick figures](https://github.com/dcf21/constellation-stick-figures).
